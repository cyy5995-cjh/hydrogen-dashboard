규제특례 데이터 최신화 실행 안내

현재 단독 파일(오프라인 HTML) 모드로 열려 있어 브라우저 단독으로는 수집 엔진을 직접 호출할 수 없습니다. 사용 중인 운영체제(Windows · macOS · iOS)에 맞춰 아래 방법으로 최신화를 수행할 수 있습니다.

1. Windows 환경 (PC)

폴더 내 [수동_규제특례_최신화.bat] 또는 바탕화면의 [수소 규제특례 최신화] 아이콘을 실행하면 산업통상부 공고문과 KIAT 포털을 교차 수집하여 즉시 갱신합니다.

2. macOS · iOS / iPadOS (Apple 운영체제)

• macOS(MacBook/iMac): 폴더 내 [macOS_수동_규제특례_최신화.command] 파일을 더블클릭하거나 터미널에서 npm run update를 실행하세요.
• 웹 서버 연동(Windows/macOS 공통): [웹공유_서버실행.bat] 또는 [macOS_웹공유_서버실행.command] 구동 후 접속하면 iPhone·iPad(iOS) 및 Mac Safari에서도 상단 [규제특례 최신화] 버튼으로 실시간 동기화가 가능합니다.
